# 本机配置

这是通用模板，没有默认服务器或凭据。首次使用由 AI 询问缺失项、验证连接，再维护用户私有副本，无需用户预先编辑。

私有配置只记录：

- CLI 可执行文件路径或 PATH 命令、管理端 HTTPS 地址。
- 静态项目（`project`）：由 `status` 取得 `id / slug / siteUrl`。
- Docker 应用（`app`）：由 `app status` 取得 `appId / slug / url`。
- 按**管理端 URL＋资源类型＋资源 ID**记录对应 Token 文件路径，或注明使用已有环境变量；不保存 Token 原文。

未标明类型的旧项目记录保留为静态项目。静态与 Docker 可以有相同 slug，不混用凭据或覆盖彼此配置，也不把上次 Token 自动用于新目标。只有查询结果与明确目标或保存身份不符、或多个凭据无法选择时才询问。

已有有效配置不重复询问；路径或凭据失效时只修复对应项。只写私有配置，不写回受 Git 跟踪的模板；用户要求仅本次使用时不保存。
