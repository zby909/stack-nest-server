# 使用平台

## 登录与成员

管理员添加成员邮箱后，成员使用邮件一次性验证码登录。添加邮箱时可选发送邀请邮件，默认关闭。

| 角色       | 权限                                         |
| ---------- | -------------------------------------------- |
| 普通用户   | 管理自己的静态项目、Docker 应用和相关日志    |
| 管理员     | 管理全部项目、普通成员，查看服务器与备份状态 |
| 超级管理员 | 另可管理管理员角色、实例资源预算和网络配置   |

超管由部署配置指定。删除普通成员会撤销其会话，并将已有项目转交管理员。

## 静态站点

1. 准备单个 `.html` / `.htm` 文件，或将 `index.html` 和配套资源打包为 ZIP / RAR。
2. 点击“部署静态项目”，填写名称与标识，选择文件。
3. 打开待发布版的独立预览地址，检查页面和资源。
4. 点击“发布此版本”，正式站点提供新内容。

压缩包可以直接包含 `index.html`，或只有一个包含它的一级目录，如 `dist/`。RAR 支持未加密的单卷归档。

单 HTML 无需打包：上传的 `报告.html` 会原样保存为站点入口 `index.html`，版本记录保留原文件名。CSS、脚本和图片请内嵌或使用外部地址；相对路径引用的本地资源不会随单文件上传。它同样支持预览、更新、回退和 ZIP 导出。

| 限制     | 上限                         |
| -------- | ---------------------------- |
| 上传文件 | 90 MiB                       |
| 解压内容 | 200 MiB                      |
| 归档条目 | 5000                         |
| 保留版本 | 当前版、上一版、一个待发布版 |

磁盘达到 90% 或无法预留处理空间时暂停上传，页面会说明原因。

## 更新与管理

更新先生成待发布版，确认发布后才替换正式站点。已有待发布版时，先发布或丢弃，再上传或回退。

版本页支持更新说明、文件变化、预览和 ZIP 导出。回退将上一版恢复为正式版；暂停保留文件，更新不会解除暂停。删除项目会清理全部保留版本。

## 上传中断

支持暂停、继续和放弃。刷新后，项目页提示未完成任务并恢复表单；重选原文件后从服务端已接收的位置继续。

任务保留 24 小时。浏览器保存恢复信息，不保存文件；文件已传完时可以直接确认结果。跨服务器迁移不保留未完成上传。

上传从 512 KiB 分片开始，网络中断后会缩小分片；连续三次自动重试仍失败时停止，保留已确认的进度。发送进度与服务器确认进度会分别显示，发送到 99% 不代表文件已保存完成。

## 访问地址

| 内容        | 示例                                 |
| ----------- | ------------------------------------ |
| 管理后台    | `stack-nest.example.com`             |
| 静态站点    | `stack-nest-{slug}.example.com`      |
| 版本预览    | `stack-nest--{版本UUID}.example.com` |
| Docker 应用 | `stack-nest--app-{slug}.example.com` |

**站点、应用和预览链接默认公开。** 邮箱登录保护后台管理操作。
