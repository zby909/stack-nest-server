# 使用指南

本页介绍成员管理和静态站点。Docker 镜像、资源限制和日志见 [Docker 应用](DOCKER_APPS.md)。脚本、AI 和 GitHub Actions 用的工具见 [命令行与自动部署](#命令行与自动部署)。

## 登录与成员

管理员添加成员邮箱后，成员使用邮件一次性验证码登录。添加邮箱时可选发送邀请邮件，默认关闭。

| 角色       | 权限                                         |
| ---------- | -------------------------------------------- |
| 普通用户   | 管理自己的静态项目、Docker 应用和相关日志    |
| 管理员     | 管理全部项目、普通成员，查看服务器与备份状态 |
| 超级管理员 | 另可管理管理员角色、实例资源预算和网络配置   |

超管由部署配置指定。删除普通成员会撤销其会话，并将已有项目转交管理员。

## 静态站点

**手头还没有文件？** 点击“创建空项目”，填写名称即可预留项目网址。创建后会进入设置，点“创建部署 Token”就能让 AI 上传首版预览。正式站点在你确认发布后开放。

AI 上传完成后，切回管理后台或打开项目的“版本”即可看到新的待发布版。确认窗口始终对应你点选的版本。

1. 准备单个 `.html` / `.htm` 文件，或将 `index.html` 和配套资源打包为 ZIP / RAR。
2. 点击“部署静态项目”，填写名称与标识，选择文件。
3. 在版本页打开独立预览，或从列表点击“预览”／“草稿预览”。
4. 在版本页点击“发布此版本”，确认后更新正式站点。

压缩包可以直接包含 `index.html`，或只有一个包含它的一级目录，如 `dist/`。RAR 支持未加密的单卷归档。

单 HTML 无需打包：上传的 `报告.html` 会原样保存为站点入口 `index.html`，版本记录保留原文件名。CSS、脚本和图片请内嵌或使用外部地址；相对路径引用的本地资源不会随单文件上传。它同样支持预览、更新、回退和 ZIP 导出。

| 限制     | 上限                         |
| -------- | ---------------------------- |
| 上传文件 | 90 MiB                       |
| 解压内容 | 200 MiB                      |
| 归档条目 | 5000                         |
| 保留版本 | 当前版、上一版、一个待发布版 |

磁盘达到 90% 或无法预留处理空间时暂停上传，页面会说明原因。

## 更新与管理

更新先生成待发布版，确认发布后才替换正式站点。已有草稿时可选择“更新待发布版”；失败保留旧稿，成功返回新预览地址。需要回退正式版时，先发布或丢弃草稿。

更新和回退保持正式网址不变；每一版有自己的独立预览地址。更早版本被清理后，对应预览链接失效。

版本页支持更新说明、文件变化、预览和 ZIP 导出。回退将上一版恢复为正式版；暂停保留文件，更新不会解除暂停。删除项目会清理全部保留版本。

项目概览和 Docker 应用详情显示最近 7 个 UTC 自然日的源站请求、页面请求、4xx 和 5xx。同一次页面打开可能触发多个资源请求，计数不代表访客数。只统计正式项目域名，预览和 CDN 边缘直接返回的访问不计入。从启用采集或项目创建时开始显示。

## 上传中断

支持暂停、继续和放弃。刷新后，项目页提示未完成任务并恢复表单；重选原文件后从服务端已接收的位置继续。

任务保留 24 小时。浏览器保存恢复信息，不保存文件；文件已传完时可以直接确认结果。跨服务器迁移不保留未完成上传。

当前版本从 512 KiB 分片开始，网络中断后会缩小分片。连续失败时最多自动重试三次。服务器确认的字节数与已发送分片不符时也会停止，保留上次确认的进度。页面分别显示发送和确认进度。

## 访问地址

| 内容        | 示例                                 |
| ----------- | ------------------------------------ |
| 管理后台    | `stack-nest.example.com`             |
| 静态站点    | `stack-nest-{slug}.example.com`      |
| 版本预览    | `stack-nest--{版本UUID}.example.com` |
| Docker 应用 | `stack-nest--app-{slug}.example.com` |

**站点、应用和预览链接默认公开。** 邮箱登录保护后台管理操作。

### 下载 CLI

从与平台配套的 [Release](https://github.com/zby909/stack-nest-server/releases) 下载 `stacknest-deploy-版本-系统-架构` 的压缩包。根据**运行 CLI 的电脑或 CI Runner**选版本，例如 Windows x64 使用 `windows-amd64.zip`，Apple 芯片的 Mac 使用 `darwin-arm64.tar.gz`。

同名 `.sha256` 保存压缩包的哈希。Linux 用 `sha256sum -c 文件.sha256`，macOS 用 `shasum -a 256 -c 文件.sha256`，Windows 用 `Get-FileHash` 对照校验值。校验后解压使用。

从源码构建，在 `server/` 执行 `go build -o stacknest-deploy ./cmd/stacknest-deploy`。Windows 输出名加 `.exe`。
