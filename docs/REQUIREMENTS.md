# 产品范围

## 1. 目标

让个人开发者和小团队的可信成员，在自己的服务器上方便地部署、更新、查看和迁移项目。

优先考虑易部署、易维护和数据可靠性。默认面向单台 Linux 服务器，不扩展为面向陌生用户的公共容器托管平台。

## 已支持

| 能力        | 范围                                               |
| ----------- | -------------------------------------------------- |
| 静态站点    | 单 HTML / ZIP / RAR、断点续传、SPA、预览和确认发布 |
| 版本        | 当前版、上一版、独立待发布版、更新说明和文件比较   |
| Docker 应用 | 已构建镜像、单个 HTTP 容器、环境变量和一个数据目录 |
| 成员        | 白名单邮箱验证码、普通用户 / 管理员 / 超管         |
| 管理        | 搜索、暂停、导出、日志、服务器与应用状态           |
| 运维        | Docker Compose、备份、完整换机迁移                 |
| 可选保护    | XFS 配额、应用公网访问与局域网保护                 |

操作见 [使用指南](USAGE.md)与 [Docker 应用](DOCKER_APPS.md)。

## 项目规则

- 普通用户管理自己的项目，管理员管理全部；归属由服务端登录身份决定。
- 静态上传文件最大 90 MiB，解压最大 200 MiB、5000 个条目；拒绝路径越界、链接和特殊文件。
- 压缩包的根目录或唯一一级目录包含 `index.html`；单 HTML 可使用任意 `.html` / `.htm` 文件名，发布时作为 `index.html`。仅接收静态内容与构建产物。
- slug 全局唯一，1–52 个小写字母、数字或连字符，不以连字符开头或结尾。
- 上传先生成待发布版，确认后原址发布；可明确更新指定待发布版，新文件校验成功后替换，失败保留旧版，版本冲突时停止。
- 暂停保留文件，更新不解除暂停；删除清理全部保留版本。
- 磁盘达到 90% 或无法预留空间时拒绝新的上传。
- 项目、应用和预览默认公开，管理权限隔离不等于访问保护。

## 当前边界

- 单个 API 实例写入数据卷。
- 不执行用户源码或 Dockerfile 构建，不编排用户多容器应用。
- 不提供公开注册、计费、集群、自定义项目域名或自动证书申请。
- 不提供访问码、任意历史版本恢复或通用的应用数据库回退。
- Docker 面向可信成员，共享内核隔离的原理见 [架构](ARCHITECTURE.md)。

## 验收

发布前完成 [后端测试](DEVELOPMENT.md#检查与测试)和 [前端回归](https://github.com/zby909/stack-nest-web/blob/main/docs/TESTING.md)。

部署后检查邮箱登录、角色权限、静态发布与回退、Docker 数据保留、备份恢复，以及已启用的配额和网络保护。

接口字段以 [OpenAPI](../openapi/openapi.yaml)及补充契约为准。
