| ---------------------------- | ------ |

| Compose 项目名               |        |
| 工作目录及配置文件           |        |
| 当前配套版本                 |        |
| 私有环境文件路径             |        |
| 证书或连接器凭据文件路径     |        |

| 文件系统及配额状态           |        |
| 应用数量 / 总内存预算        |        |
